Lever 1 — Tiling cracks dense-sheet confabulation

On dense sheets (framing, grading), Sonnet 4.6's 1568px server-side image cap shrinks the drawing until fine call-outs blur — the model stops reading and starts confabulating. Two real failures, single-image: Walpole C-401 grading R 0.100 (1/10 found) and San Marcos S-201 framing R 0.077 (1/13). The fix: split the sheet into ≤1568px tiles so every region is read at full resolution.

Lever 2 — Precision post-processing pays the tiling tax

Tiling buys recall but inflates output: the same markup gets reported from adjacent tiles, plus location-only noise. Raw tiled extraction balloons the return count and precision drops. markup-postprocess.js fixes it deterministically — drop location-only markers, Jaccard cross-tile dedup (≥0.6), unique-ID renumber with related_to remapping.

Dedup collapses 31 raw returns to 23 real ones. Same pass lifted San Marcos S-201 precision 0.379 → 0.625 with recall held (commit e48ce35).
